# Product Roadmap

## 1. Reliable service operations

Harden the order terminal and KDS around the current explicit workflows: rapid
touch order capture, modifier/variant accuracy, KOT routing, station views,
elapsed-time alerts, void reasons, split/multi-tender payment safeguards, receipt
and kitchen-print acknowledgement, and local-first synchronization foundations.

## 2. Back-office control

Complete catalog, recipes, stock transactions, purchasing, wastage, supplier
records, tax/price/channel rules, shift/cash management, roles, audit search,
and actionable outlet reporting. Keep inventory movements transaction-led and
financial changes auditable.

## 3. Multi-outlet and integrations

Add outlet configuration, station/device setup, centrally governed menus,
cross-outlet reporting, migration-safe integrations, and reliable import/export.
Each integration enters through an explicit contract and event mapping.

## 4. Guest commerce

Add QR table ordering, kiosk/pickup flows, delivery/aggregator ingestion,
customer-facing status, loyalty, and customer communications only after their
effects on payments, KDS capacity, menu availability, and customer consent are
specified.

## Quality gates for every phase

Plan against the competitor baseline in `plan.md`; document workflow/ADR changes;
validate touch, keyboard, accessibility, loading/error/offline states; and cover
important command transitions with automated tests before release.
